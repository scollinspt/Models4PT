# Models4PT Frontend

Scaffolded Vite + React + TypeScript frontend.

Commands

```bash
# install deps
npm install

# run dev server
npm run dev

# build
npm run build
```

Notes

- The frontend assumes the backend is available at the same origin during development. If the backend runs on a different port, configure a proxy in `vite.config.ts` or set `axios.defaults.baseURL` accordingly.
